## Publicar en GitHub Pages

1. Crea un repositorio llamado `USUARIO.github.io` (cambia USUARIO por tu usuario de GitHub).
2. Sube estos archivos a la rama `main`.
3. En **Settings → Pages**, elige *Deploy from a branch* → `main` / `root`.
4. En uno o dos minutos queda en `https://USUARIO.github.io`.
